익명 글쓰기

숙성된 예치금에서 보증금을 걸면, 1시간에 익명 메시지를 보증금만큼 보낼 수 있어요(최대 30개). 익명 글 1개, 또는 익명 좋아요 최대 16개 묶음 1개가 메시지 1개예요. 1개당 보증금은 저장 가격을 따르고, 익명 차선이 많이 예약될수록 커져요. 한도를 넘겨 같은 번호로 다른 글을 쓰면 비밀키가 드러나 보증금이 몰수돼요.

다른 기기에서 같은 익명 키로 글을 쓰고 있어요. 두 기기가 같은 번호를 쓰면 보증금이 몰수돼요. 이 노드의 익명 글쓰기를 멈췄어요.
