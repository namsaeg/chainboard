# chainboard

검열에 저항하는 탈중앙 게시판입니다. 글은 전용 블록체인에, 첨부 파일은 채굴자들이 나눠 저장하는 P2P 저장소에 올라갑니다. 채굴력은 **얼마나 많은 데이터를 실제로 저장하고 있는가**로 정해집니다.

> **0.5.0은 테스트넷 전용 프로토타입입니다.** 보안 감사를 받지 않았고, 익명 차선의 신뢰 설정도 테스트넷용 단독 설정입니다. 실제 가치를 가진 코인으로 쓰지 마세요.

## 빠른 시작 (Windows)

Go 1.24 이상이 필요합니다. 의존성은 `vendor/`에 들어 있어서 인터넷 없이도 빌드됩니다.

```powershell
git clone https://github.com/namsaeg/chainboard
cd chainboard
go build -o chainboard.exe ./cmd/chainboard

# 혼자 써 보기: 빠른 로컬 개발망에서 채굴하며 실행
.\chainboard.exe -network devnet -mine -pledge-gb 1
```

미리 빌드된 `chainboard.exe`를 받았다면 압축을 풀고 같은 명령으로 실행하면 됩니다. 서명되지 않은 실행 파일이라 Windows가 경고하면 "추가 정보 → 실행"을 누르세요.

브라우저에서 <http://127.0.0.1:7780> 을 열면 게시판 화면이 나옵니다. 채굴로 코인이 생기면 수수료 차선에 글을 쓸 수 있어요.

**익명으로 무료로 쓰려면**: 지갑 카드의 "예치"로 코인을 예치하고, 숙성될 때까지 기다립니다(testnet 7일, devnet 5블록). 그다음 "익명 글쓰기"에서 보증금을 걸고 등록하세요. 보증금만큼 1시간에 익명 글을 쓸 수 있습니다(최대 30개, 차선이 한산할 때 1개당 약 1코인 — 저장 가격과 익명 차선 예약률을 따라 움직여요). 글에는 "등록된 회원 중 누군가"라는 영지식 증명만 붙고, 지갑 주소는 드러나지 않아요. 익명 글은 1개월 동안 보관돼요. 이번 에포크의 마지막 글을 쓰기 전에는 꼭 확인을 받아요.

**오래 남기고 싶은 글**은 수수료 차선에서 보존 기간(1개월 ~ 100년, 영구)을 고르세요. 오래 남길수록 비싸고, 누구나 수수료를 내고 다른 사람의 글을 연장할 수 있어요.

**좋아요**는 바로 나가지 않고 모였다가 10분마다(또는 100개가 차거나 "지금 보내기"를 누르면) 한 번에 나가요. 나가기 전에는 취소할 수 있어요. 글이 올라온 뒤 30일 안의 좋아요만 셉니다.

**크라우드 펀딩**: 코인이 없어도 남기고 싶은 파일이 있으면 "모금 요청 만들기"로 요청 코드를 만들어 나눠 주세요. 후원자는 코드를 붙여 넣어 데이터 일부를 직접 확인한 뒤 후원합니다. 모인 코인은 그 파일을 저장하는 데만 쓰이고, 마감까지 저장·증명되지 않으면 후원자에게 저절로 돌아가요. 저장되고 나면 되돌릴 수 없어요.

여러 노드를 연결하려면 다른 PC에서 `-seeds 192.168.0.10:7700` 처럼 첫 노드의 주소를 넣으세요.

### 주요 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-network` | `testnet` | `testnet` 또는 `devnet`(빠른 로컬 시험용) |
| `-datadir` | 사용자 설정 폴더 | 블록, 지갑 키, 저장 데이터 위치 |
| `-listen` | `:7700` | P2P 수신 주소 |
| `-seeds` | 없음 | 처음 연결할 노드들 (`host:port,host:port`) |
| `-http` | `127.0.0.1:7780` | 웹 UI·API 주소. 지갑을 제어하므로 localhost에서 바꾸지 마세요 |
| `-mine` | `false` | 데이터를 저장하고 채굴 |
| `-pledge-gb` | `100` | 저장에 내놓을 디스크 용량(GB) |
| `-send-delay` | testnet 5분, devnet 0 | 내 트랜잭션을 내보내기 전 최대 무작위 지연 |

보낸 글은 발신자를 숨기려고 무작위 지연과 Dandelion++ 경로를 거치므로, 다른 노드에 보이기까지 testnet에서 수 분 걸릴 수 있습니다. 그 사이 앱을 꺼도 보낼 것은 `outbox.json`에 남아 다음 실행 때 이어서 나갑니다.

`<datadir>/<network>/` 아래 키 파일은 평문으로 저장됩니다(아직 암호화하지 않습니다). 백업하고 남에게 보여 주지 마세요.

| 파일 | 내용 |
|---|---|
| `wallet.key` | 지갑(계정) 키 |
| `node.key` | P2P 신원 키(지갑과 분리) |
| `rln.key` | 익명 차선 회원 비밀값. 가진 사람은 회원으로 글을 쓸 수 있어요 |
| `rln_used.json` | 이번 시간에 쓴 메시지 번호. **지우거나 다른 PC로 rln.key만 옮겨 쓰면 같은 번호를 다시 써서 보증금을 잃을 수 있어요** |
| `pseudonym.key` | 가명 서명 키(처음 가명으로 쓸 때 생김) |
| `chain.db`, `store.db` | 블록, 데이터 청크·글 본문 |
| `packed/` | 채굴용 패킹된 사본(평면 파일). 지우면 다시 패킹해요 |
| `likes.json` | 아직 나가지 않은 좋아요 |
| `fund.json` | 내가 만든 모금 요청(모이면 이 노드가 업로드·증명해요) |
| `index.db` | 게시판·스레드 색인. 지워도 다음 실행 때 체인에서 다시 만듭니다 |
| `chain.db.xxxx.old` | 다른 네트워크(예: 이전 테스트넷)의 블록. 필요 없으면 지워도 됩니다 |
| `outbox.json` | 아직 나가지 않은 내 트랜잭션과 익명 글 |

## 무엇이 들어 있나

- **저장 기반 합의**: Arweave식 저장 증명. VDF(순차 SHA-256, 1초 단계)가 도전 횟수를 제한하므로 CPU가 아니라 저장량이 채굴력이 됩니다. 단계마다 파티션당 연속 구간 하나(512 KiB)를 순차로 읽으므로 HDD로도 채굴할 수 있습니다(20 TB에 초당 36번 읽기). 청크는 채굴자 주소·위치마다 Argon2id로 고유하게 인코딩(packing)되어 한 사본을 여러 주소로 우려먹을 수 없습니다.
- **보존 등급**: 첨부와 글 본문 모두 1개월 / 1~100년 / 영구 중 선택(익명 글은 1개월 고정). 누구나 비용을 내고 연장할 수 있습니다. 기간제 데이터는 만료 시점별 버킷에 모였다가 통째로 만료됩니다. 이미 저장된 파일을 다시 올리면 재사용하고, 더 긴 등급을 고르면 자동으로 연장합니다.
- **블록에는 해시만**: 블록에 실린 것은 영원히 남으므로, 글 본문은 블록에 넣지 않습니다. 트랜잭션은 본문 해시에 서명하고, 본문은 트랜잭션과 함께 네트워크로 전달된 뒤 1시간마다 저장소에 묶여 들어가 채굴자들이 나눠 보관합니다. 최근 글은 모든 노드가 갖고 있어 바로 읽히고, 오래된 글은 열 때 받아옵니다.
- **차선**: 익명 차선(무료, 텍스트 전용, 용량의 30%)과 수수료 차선(EIP-1559식 기본 수수료 소각). 블록에 영원히 남는 바이트는 영구 저장 단가 아래로 내려가지 않습니다(지금 글 하나 약 0.0008코인).
- **스팸 할증**: 같은 글(32바이트 이상)을 하루 안에 반복하면 기본 수수료가 2배씩, 한 계정이 시간당 30개 속도를 넘겨 보내면 10개 초과마다 2배씩 오릅니다. 할증이 붙을 때는 노드가 배수와 예상 수수료를 보여 주고 확인을 받습니다.
- **익명 차선(RLN)**: 예치 보증금으로 회원 트리에 등록하고, 글마다 Groth16 영지식 증명으로 "회원이고 이번 시간 n번째 글"임만 보입니다. 한도를 넘겨 같은 번호를 다시 쓰면 비밀값이 드러나 누구나 보증금을 몰수할 수 있습니다. 원하면 예치 계정과 무관한 가명 키로 서명할 수 있습니다.
- **경제**: 업로드 수수료는 기금(영구)·에스크로(기간제)로 들어가 저장 노드에 나눠 지급됩니다. 발행은 6개월 증가 → 4년 반감 → 저장 용량 비율 피드백 꼬리 발행. 모든 가격은 "원시 1GB를 1년 저장" 단위로 매겨지고, 체인이 관측한 저장 가격(30일 이동평균, 하루 ±5%)으로 코인 환산됩니다.
- **좋아요 묶음**: 좋아요는 체인 상태가 아니라 각 노드 색인이 셉니다. 짧은 참조로 묶어 보내 하나씩 보낼 때의 1/14 크기입니다.
- **크라우드 펀딩**: 해시 잠금(데이터 루트) + 시간 잠금(마감) 에스크로. 저장·증명되면 확정, 아니면 자동 환불.
- **상태 루트**: 블록 헤더가 상태 전체의 루트를 담습니다(나중에 가벼운 클라이언트가 쓸 바탕).
- **이탈 방지**: 채굴 수입의 75%는 180일 동안 풀리며, 저장 증명을 계속해야 받을 수 있습니다. 3에포크 연속 증명이 없으면 몰수되어 복구 보상 풀로 갑니다.
- **네트워크**: 상호 인증 TLS 1.3(겉보기에는 일반 HTTPS), Dandelion++ 전파, 내 트랜잭션은 무작위 지연 후 순서대로 묶어 발송. 노드 키와 지갑 키를 분리해 네트워크 신원이 계정과 연결되지 않습니다.
- **악성 파일 방어**: 업로드 이미지는 PNG/JPEG/GIF만 받고 픽셀부터 다시 인코딩해 메타데이터와 숨은 페이로드를 지웁니다. 브라우저에는 허용된 이미지 형식만 제공합니다.
- **서명**: Ed25519 (결정적 논스, 상수 시간 구현, 빠른 검증).

자세한 규칙은 [DESIGN.md](DESIGN.md), 이번 버전의 범위와 한계는 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

## 개발

```sh
go vet ./...
go test ./...          # 노드 3개를 실제 TLS로 연결하는 통합 테스트 포함
go test -race ./...
```

의존성은 효율과 검증된 안정성이 확실한 것만 씁니다. 모두 `vendor/`에 들어 있습니다.

| 라이브러리 | 용도 |
|---|---|
| `golang.org/x/crypto/argon2` | 패킹용 메모리 하드 함수 |
| `go.etcd.io/bbolt` | 블록·청크 저장 (단일 파일, 원자적 쓰기) |
| `github.com/consensys/gnark`, `gnark-crypto` | RLN 회로, Groth16, BN254, MiMC |

`go.mod`의 `replace` 줄은 개발 환경에서 Go 모듈 프록시가 막혀 있어 같은 모듈의 공식 GitHub 미러를 가리키게 한 것입니다. 내용은 같고, vendor 빌드에는 영향이 없습니다.

```
cmd/chainboard     실행 파일 (노드 + 웹 UI)
cmd/rlnsetup       RLN 증명 키 다시 만들기 (테스트넷용 단독 설정)
internal/params    네트워크 파라미터 (합의 상수)
internal/cryptox   해시, Ed25519 키, 주소
internal/codec     정규 바이너리 인코딩
internal/merkle    머클 트리
internal/chunk     256KiB 청크 / 8KiB 하위 청크와 데이터 루트
internal/pack      채굴자별 고유 인코딩 (Argon2id)
internal/vdf       순차 해시 체인 (전체·표본 검증)
internal/rln       RLN 회로, 증명·검증, 회원 트리
internal/types     트랜잭션과 블록
internal/state     상태와 상태 전이 함수 (합의 규칙 전부)
internal/chain     블록 보관(bbolt), 가장 무거운 체인 선택, 재구성
internal/pmap      퍼시스턴트 해시 트라이와 청크 벡터 (상태 버전을 O(1)로 복사)
internal/mempool   대기 트랜잭션, 이중 신호 감지
internal/store     청크·본문 저장(bbolt)과 패킹된 사본(평면 파일)
internal/miner     파티션 할당·패킹·채굴·에포크 증명
internal/p2p       TLS 전송, 가십, Dandelion++, 동기화, 청크 교환
internal/media     이미지 검사와 재인코딩
internal/node      전체 조립, 지갑, 지연 발송, 익명 글 증명, 글 색인
internal/api       로컬 HTTP API와 웹 UI
```
